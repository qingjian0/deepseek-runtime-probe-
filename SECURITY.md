# Security Policy

This repository contains an Android runtime metadata probe and research documentation for authorized testing.

Do not publish access tokens, API keys, cookies, signing keys, personal data or proprietary APK contents in issues or pull requests. Report vulnerabilities privately through GitHub private vulnerability reporting where available.

The probe must not persist chat text, prompts, reasoning, request/response bodies, cookies, bearer tokens, API keys, PoW answers, file contents, images or account identifiers.

A GitHub personal access token was pasted into an earlier conversation. Its value is deliberately not reproduced. Revocation status cannot be verified from this workspace; the owner should revoke it and review token activity. Never reuse it.
