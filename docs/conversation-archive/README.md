# Conversation Archive

This directory contains reconstructed records from conversation context and prior-chat summaries. It is not a verbatim export of every ChatGPT message.

Policy: preserve user requirements separately from assistant hypotheses; preserve changes and rejected directions; do not invent missing messages or timestamps; link attachments through the artifact manifest; mark unavailable branches and missing files explicitly.

- Branch/subthread index: branch-index.md
- Recovered decisions: decisions.md
- Missing history: missing-history.md
